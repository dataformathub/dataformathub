Common Mistakes When Opening CSV Files in Excel

1. All Data Appears in a Single Column

Why it happens: Some regions use a semicolon (;) instead of a comma (,) as the default list separator in Excel.

How to fix it: Open a blank workbook in Excel, go to Data → From Text/CSV, select your file, and choose Comma as the delimiter before clicking Load.

2. Leading Zeros Disappear (e.g., 00123 becomes 123)

Why it happens: When you double-click a CSV file directly, Excel automatically treats numeric strings like zip codes, phone numbers, or IDs as plain numbers and removes leading zeros.

How to fix it: Use Data → From Text/CSV instead of double-clicking the file, and set that column's data type to Text during import.

3. Special Characters or Accents Look Broken

Why it happens: Older versions of Excel sometimes open UTF-8 CSV files using the wrong character encoding, turning symbols or non-English letters into strange characters.

How to fix it: Import the CSV through Data → From Text/CSV and select 65001: Unicode (UTF-8) as the File Origin.

4. Long Numbers Turn into Scientific Notation (1.23E+11)

Why it happens: Numbers with more than 11 digits (such as tracking numbers or order IDs) are automatically formatted in scientific notation by Excel.

How to fix it: Import the column as Text via the Text Import Wizard so Excel keeps every digit intact.
